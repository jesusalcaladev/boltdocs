**Adoption — polish + lowering the barrier to entry**

- Reorganized guides — Navigation, Headers, and CSP as their own sections
- `boltdocs migrate` MVP — VitePress first
- Roadmap post + real-world migration case studies (EN/ES blog)

**Instant — the power core**

- Instant Navigation — prefetch, View Transitions, no page reload
- Add Redirect — redirects via config with 301/308 and loop detection
- Virtual routes — routes generated by plugins
- Speed optimizations — Shiki pool, dynamic chunking, SSG cache
- Search and primitive improvements — consolidate the public API

**Content Superpowers — the MDX wave**

- plugin-tabs-sync — tabs synced across pages
- plugin-reading-time — reading time derived from content
- plugin-last-updated — date from git
- plugin-contributors — authors from git
- plugin-video — YouTube, Loom, Vimeo
- plugin-code-diff — diffs for migration guides
- plugin-shiki-twoslash — inline TS annotations
- `<Steps>` and `<Comparison>` components

**Trust & Integrations**

- plugin-cookie-consent — GDPR
- Plausible / Fathom — privacy-first analytics
- Pagefind — local search without a backend
- Utterances — GitHub-based comments
- Hotjar — heatmaps and session replay
- plugin-meilisearch — self-hosted search
- plugin-directive — custom directives in MDX

**Ecosystem & DevEx**

- `boltdocs create-plugin` — plugin scaffolder
- plugin-storybook — embed stories
- Full `boltdocs migrate` — Docusaurus and Nextra

**Boltdocs Theme**

- The official Boltdocs theme — the product theme for the Boltdocs brand.
