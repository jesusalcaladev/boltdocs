This page groups the API surface into clear sections and points to examples and best-practices.

Sections

- Hooks: `useConfig`, `useRoutes`, `useTheme`, `useSearch` — UI & runtime helpers.
- Utilities: `defineConfig`, `createStructuredData` — config and SEO helpers.
- Plugin API: lifecycle hooks, virtual modules, middleware, server, HMR, diagnostics.
- Structured Data: JSON-LD helpers for SEO.

Guidance

- Prefer type-safe helpers (`defineConfig`) in `boltdocs.config.ts`.
- Use `createStructuredData` for canonical JSON-LD to avoid manual mistakes.
- When writing plugins, follow the `SecureBoltdocsPlugin` schema and validate paths to avoid traversal.

Examples

- Hooks: small code snippets showing `useRoutes()` to render a custom `Sidebar.Items` list.
- Plugin: scaffold showing `createPlugin({ name, hooks: { transformMdx } })`.
